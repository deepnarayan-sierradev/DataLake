Product Vision

Enterprise Data Lake Platform

A governed, metadata-driven pipeline that turns siloed source systems into one trusted, entity-resolved analytics foundation — connected into a digital twin, exposed through a governed semantic layer, and paired with a self-service control plane that lets each tenant configure it without engineering.

Draft V1

The Backbone

DL

The Governed Pipeline

One metadata-driven backbone carries every record from source system to trusted analytics — extraction, quality, resolution, the digital twin, a semantic layer and serving — tenant-scoped and fully audited from end to end.

01

Metadata & configuration

Connectors, entities, field mappings and tenant config live as versioned data. New sources onboard by configuration, not code.

02

Ingestion lifecycle

Scheduled extraction, watermark-based delta sync, an immutable raw layer and schema-drift detection on every run.

03

Trust & governance

Data-quality gates, PII masking, lineage, retention and legal hold, behind a six-gate source-onboarding workflow.

04

Twin, semantics & serving

Golden records connected into a digital twin, exposed through a governed semantic layer, and delivered to a multi-engine serving store.

SS

Self-Service Configuration

Tenant users configure connectors, mappings, resolution rules, schedules and serving stores through a permission-gated web console — with draft/publish, dry-run validation and maker-checker approval. Engineering is no longer in the loop for onboarding.

Modular Product Model

Composable modules on one pipeline

Each module is an independently deployable part of the same metadata-driven platform — sharing one tenant model, one versioned configuration system and one audit trail.

CR

Connector Runtime & Orchestration Backbone

Adapter-and-registry source connectors (Salesforce, MySQL RDS, NetSuite, Sage Intacct, Sage X3) driven by EventBridge → SQS FIFO → Step Functions → Lambda, with watermark delta sync and an immutable raw layer.

T

Transformation & Data Quality

Versioned field mapping, type-casting, PII masking, quality gates (null/range/pattern/enum) and SCD Type-1 merge.

R

Entity Resolution & Golden Records

Deterministic and probabilistic matching with config-driven survivorship, field provenance and stable golden IDs.

S

Serving Store

Five engines — MySQL, PostgreSQL, SQL Server, Azure SQL, Redshift — with idempotent upsert and per-tenant isolation.

G

Governance & Observability

Six-gate onboarding, classification, lineage, retention and legal hold; structured logs, metrics, tracing and a DLQ with replay.

C

Control Plane & Console

Cognito/JWT API plus a self-service React console — draft/publish, dry-run validation, maker-checker approval and monitoring.

TW

Digital Twin

Connects golden records into one entity with its relationships, lifecycle and rollups — a 360° view per company, contract and supplier.

SM

Semantic Layer

Governed metrics, dimensions and joins over the golden layer, so every tool and query computes the same numbers the same way.

AI

Conversational Agent

Natural-language questions become governed answers through a verification loop, with saved, re-runnable named queries.

DB

Dashboards & Reporting

Tenant-scoped, permission-aware dashboards built on saved semantic queries — one consistent set of governed definitions.

The Four Data Layers

Raw (Bronze)

Every source record exactly as received. Immutable, Object-Lock, 7-year retention.

Curated (Silver)

Canonical field names, quality-checked, PII-masked. Full current-state per entity.

Analytics (Gold)

Entity-resolved golden records that power the Digital Twin and semantic layer — Glue-catalogued and Athena-queryable.

Serving

Relational export for BI & apps — Redshift, MySQL, PostgreSQL, SQL Server, Azure SQL.
